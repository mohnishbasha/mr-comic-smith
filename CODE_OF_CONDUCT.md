# Code of conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and keep discussion about the work. Harassment of any kind
is not tolerated. Report concerns privately to the maintainers through GitHub (Security tab or a
direct message to @mohnishbasha). Maintainers will respond within 72 hours and keep reports
confidential.
